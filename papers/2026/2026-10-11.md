### 1. Caught in the Act: Probes Effectively Detect Sabotage and Catch Unverbalized Deception ★

- arXiv：[2610.12445](https://arxiv.org/abs/2610.12445) · [在网站阅读](https://aisafetyhot.com/items/bp1e2e7mg03hqoq6khww30za7)
- 本站收录：2026-10-11 · 原文发表：2026-10-09（北京时间）
- 作者：Oskar J. Hollinsworth; Alex F. Spies; Tigist Diriba; Adam Gleave; Chris Cundy

**导读**：FAR.AI 等机构的研究者提出用白盒激活探针检测大语言模型的知情谎言，在 SHADE-Arena 上取得 98.8% AUC，超过 Opus 5.5 文本监控基线。研究者构建了迄今规模最大的谎言数据集 fibs，包含 163,016 条转录、28 个数据族，并设计了可在层与 token 两个维度聚合信息的 axial 探针等四种架构。在 Qwen3.5-397B-A17B 上，四个用完整 fibs 训练的探针得分 0.979 至 0.984，高于 Opus 5.5 的 0.960；探针性能随底层模型规模提升而改善。在无法仅凭上下文判断的内省型谎言场景中，探针能以最高 99.7% AUC 区分模型真实隐藏目标与其他目标，也能识别开源权重模型在政治敏感话题上的虚假陈述。研究者将公开 fibs 数据集与训练好的探针。

**速读**（据 [论文 PDF（AI 生成）](https://arxiv.org/abs/2610.12445) 整理，以论文原文为准）：

- **问题**：黑盒监控成本高且依赖脆弱思维链，却要检出智能体的明知虚假。作者检验：上下文虚假上训练的白盒探针能否迁到SHADE-Arena在线监控和内省虚假。
- **方法**：构建163,016条、28族的FIBS，训练LinearEnsemble、MLPEnsemble、EFC与轴向探针，读深度30%–90%的六层。监控时预填追问，用Yes与No对比分数给步骤打分，不读思维链。
- **实验与结果**：Qwen3.5-397B-A17B上，14个场景的四探针AUROC为0.979–0.984，Opus 5.5*为0.960。更大模型上探针更高。bird-labs企业档AUC达99.7%，math-sandbagger为63%。
- **局限与可以继续做的**：作者称探针受模型信念限制，并询问数据扩展是否有上限。FIBS含推理行仅5.5%，且几乎全为off-policy。评测含五个Qwen3.5、三个Nemotron-3、Kimi K3与八个生物体；论文未报告人工一致性与具体算力开销。

### 2. Predicting Alignment Generalization with Value Representations

- arXiv：[2610.12410](https://arxiv.org/abs/2610.12410) · [在网站阅读](https://aisafetyhot.com/items/qaiv4nqmbku6uivr0b5hh8hzl)
- 本站收录：2026-10-11 · 原文发表：2026-10-09（北京时间）

**导读**：论文提出对齐泛化预测任务，即预测将模型微调为遵循某一价值观后，其在大量未见的其他价值观上行为会如何变化。作者对现代对齐目标中的 66 种价值观做了大规模泛化效应分析，并在该预测任务上评测多种表征方法：基于模型在上下文中应用价值观时激活的表征显著优于基于价值观文本描述的方法，最佳激活方法与该泛化矩阵的相关性为 0.45，描述类基线为 0.05。作者还用这类表征衡量多价值观对齐目标中各价值观的相似度，发现其与模型鲁棒性显著相关，并给出存在共享、与模型无关的价值观空间的初步证据，据此构建了首个基于实证泛化动态的 LLM 价值观分类体系。

**速读**（据 [论文 PDF（AI 生成）](https://arxiv.org/abs/2610.12410) 整理，以论文原文为准）：

- **问题**：alignment target 中的价值经后训练写入模型后，窄行为仍可能意外改变未见情境中的行为。作者要在训练前预测：微调遵循某一价值，会如何改变大量未训练价值上的倾向。
- **方法**：在 CONSTITUTION 上做单价值 DPO 与 SFT，用 ConflictScope 得到泛化矩阵 G。比较描述嵌入、行为嵌入和 PERSONA、GRADIENT、WEIGHT 的相似度能否预测 G，再用于多价值连贯性与 VALUE MAP。
- **实验与结果**：PERSONA 对 G 的汇总 ρ 为 0.45，描述嵌入为 0.05（Table 1）。Qwen-3-8B 上连贯性与 prefill 鲁棒性 ρ 为 0.43（图3，PERSONA）。VALUE MAP 汇总分数 2.61±0.13，高于两既有分类（Table 3）。
- **局限与可以继续做的**：结论提出可更稳健地预测对齐泛化、考察特质如何写入微调数据，并把 VALUE MAP 用于更现实的对齐训练。实验覆盖四个基座的 DPO 与 SFT、49 个 DPO 价值、Qwen-3-8B 上 64 个六价值目标，以及 266 个价值的分类；未报告训练重复次数。

### 3. SSCBench: Evaluating the Evidential Validity of Fault-Injection Tests for Tool-Using LLM Agents

- arXiv：[2610.11514](https://arxiv.org/abs/2610.11514) · [在网站阅读](https://aisafetyhot.com/items/ng8ntwptnb3ikrd56av4hsx6b)
- 本站收录：2026-10-11 · 原文发表：2026-10-08（北京时间）

**导读**：SSCBench 评估面向工具调用 LLM Agent 的故障注入测试在证据上是否成立。作者在两个 τ-bench 环境、四类故障和五种 Agent 配置下分析了 1,191 次故障执行，区分反证可获取与执行中实际可见。在 44 次最终看到反证但仍出现错误采纳的执行中，17 次在首次使用前看到反证，27 次在之后。作者指出，合并统计可能掩盖支撑具体结论的样本量。

### 4. RAGStress: A controlled benchmark for evaluating retrieval-augmented generation under knowledge-base degradation

- arXiv：[2610.04691](https://arxiv.org/abs/2610.04691) · [在网站阅读](https://aisafetyhot.com/items/bh2qmazd3v1o2mae1msuoyuy9)
- 本站收录：2026-10-11 · 原文发表：2026-10-04（北京时间）

**导读**：论文提出 RAGStress，一个在知识库系统性损坏下压力测试 RAG 系统的受控评测基准。基准覆盖四类自然污染（事实篡改、数字错字、相关性投毒、矛盾注入）与三级严重度（轻微、中等、明显），基于 57 个 MMLU 科目、182,546 篇文档构建单知识库、带元数据过滤的实验设计。在 52,500 次模型-问题-条件评测中，结果显示干净检索会掩盖鲁棒性差异，语义保真类污染比信号效用扰动危害更大，无检索准确率无法预测损坏检索下的鲁棒性，混合知识库准确率不应视为最坏情况鲁棒性。作者同时公开生成脚本、污染提示词、元数据 schema 和评测代码，并说明该基准用于受控压力测试，而非通用模型排行榜。

**速读**（据 [论文 PDF（AI 生成）](https://arxiv.org/abs/2610.04691) 整理，以论文原文为准）：

- **问题**：RAG通常在干净知识库上评测，真实库却会积累录入错误、版本冲突、OCR噪声和过时内容。模型在参数先验与检索上下文之间仲裁，损坏证据可能被打折，也可能被照抄。
- **方法**：RAGStress把四种损坏、三档severity放进同一向量库，查询时用元数据过滤固定检索器与索引。Claude 3 Haiku由57个MMLU科目生成182,546篇文档；700道分层题、五个系统、中性提示、选项精确匹配。
- **实验与结果**：干净检索下五模型为98.6%–100.0%（Table 1）。事实损坏与矛盾注入平均降10–71个百分点，相关性投毒不超过5个百分点（Table 6）。无检索准确率不能预测损坏下的稳健性，混合库也不是最坏情况。
- **局限与可以继续做的**：作者将范围限于选择题，文档由基准题派生，损坏由Claude 3 Haiku生成，severity无人工校验。后续包括开放问答、检索与分块交互，以及过滤、矛盾检测和弃答等防御。实验为五系统、15条件、每格700题。

### 6. Measuring Cultural Alignment Beyond the Average: A Framework for Evaluating Maternal-Health LLM Interactions in Indian Contexts

- arXiv：[2610.11586](https://arxiv.org/abs/2610.11586) · [在网站阅读](https://aisafetyhot.com/items/plv4ki45epodovlf9m1h7n3gv)
- 本站收录：2026-10-11 · 原文发表：2026-10-08（北京时间）

**导读**：研究者提出 MH-INDIC，一个面向印度北部城市与半城市语境孕产妇健康交互的文化对齐评估框架，用十维度孕产妇健康推理刻画文化行为。基于对 102 名孕产妇的 26 项调查，团队评估了 10 个 LLM，发现多个模型接近人群层面的文化分布，但所有系统在人口与家庭画像上的行为差异都明显低于人类队列。用对齐度最高的专有与开源模型生成对话时，人类接地条件提示带来更强的画像对齐与对话质量评分。

**速读**（据 [论文 PDF（AI 生成）](https://arxiv.org/abs/2610.11586) 整理，以论文原文为准）：

- **问题**：医疗LLM评测多看事实、安全与流畅，看不出母婴互动是否按家庭权威、社区规范和情绪披露来推理。作者认为这一点在母婴照护里重要，因为决策嵌在家庭与社区关系中。
- **方法**：MH-INDIC把Hofstede六维改到母婴互动层，并加MAFC、BTB、SVO、MHS。102名孕产妇与十个LLM答同一26题问卷，比较人群均值和画像间变异；再用人类分数或模型自答来生成对话。
- **实验与结果**：T=0.3时Claude的Euclidean为0.253。作者称各模型条件敏感度都低于人类的0.199。human-grounded专家PAS：Claude 0.86，Qwen3 0.83。
- **局限与可以继续做的**：作者称队列偏城市、本科，多为印度教或穆斯林，未必推广到农村或较低读写能力人群。十维不含经济约束与医疗可及性。对话为22段、两个模型、三种条件，专家只评十维中的三维。作者计划扩展人群，并研究多会话与保持临床安全的行为适应。
